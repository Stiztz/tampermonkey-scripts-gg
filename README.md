# VLR.gg PLM Stats Extractor

Userscript de Tampermonkey para extraer estadísticas de partidas de Valorant desde vlr.gg. 
Muestra kills, K/D/A, marcador de rondas con tipo de ganada, y un modo de duelos 
1v1 entre jugadores.

## Características

- 📊 Stats por mapa: K/D/A por jugador, kills resaltados
- 🎯 Toggle All / Attack / Defend para stats por lado
- ⚔️ Modo Duels: compara hasta 5 duelos entre jugadores de ambos equipos
- 🗺️ Selector de mapas con nombre y duración
- 🎨 Visualización de rondas con íconos de tipo de victoria (elim, defuse, boom, time)
- 📋 Botón "Copy as text" para exportar los datos en formato legible
- 🔄 Auto-update vía GitHub

## Uso

- Compatible con `vlr.gg` y `raiden.oddin.gg`
- Botón flotante "📊 PLM" en la esquina inferior derecha
- Pega el link del match de vlr.gg y click en "Load Match"
